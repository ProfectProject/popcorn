## 🔥 Order 도메인 적용 상세

### 🛒 OrderCommandController
**핵심 CRUD 작업에 종합적 보안 적용**

```java
// 주문 생성 - 최고 보안 수준
@PostMapping
@RateLimit(requests = 10, window = 60, keyExpression = "#authentication.principal.userId")
@ApiLogging(message = "주문 생성", includeRequest = true, maskSensitiveData = true)
@ValidateRequest(validateNulls = true, validateEmpty = true)
@AuditLog(action = "ORDER_CREATE", resource = "ORDER", level = AuditLog.Level.INFO)
@Idempotent(keyExpression = "#authentication.principal.userId + ':create_order:' + T(java.time.LocalDate).now() + ':' + #request.popupId")
@RetryOnFailure(maxAttempts = 3, exponentialBackoff = true)
```

**보안 매트릭스:**
- 🔒 **Rate Limiting**: 사용자당 분당 10회
- 🛡️ **Idempotency**: 일일 팝업별 중복 방지
- 📝 **Audit Log**: 모든 주문 생성 기록
- ✅ **Validation**: 완전한 입력 검증

### 🔍 OrderQueryController
**성능 최적화 중심 설계**

```java
// 주문 목록 조회 - 캐싱 최적화
@GetMapping
```

**성능 매트릭스:**

- ⚡ **Rate Limit**: 분당 30회 (조회는 관대)
- 🔄 **Retry**: 네트워크 오류 대응

## 💰 Payment 도메인 적용 상세

### 💳 PaymentController
**금융 거래 최고 보안**

```java
// 결제 상태 변경 - 금융 보안 최고 수준
@PatchMapping("/payments/{paymentId}/status")
@RateLimit(requests = 5, window = 60, algorithm = RateLimit.Algorithm.SLIDING_WINDOW)
@ApiLogging(message = "🔒 결제 상태 변경", level = ApiLogging.LogLevel.WARN, maskSensitiveData = true)
@ValidateRequest(validateNulls = true, exceptionType = SecurityException.class)
@AuditLog(action = "PAYMENT_STATUS_CHANGE", resource = "PAYMENT", level = AuditLog.Level.WARN)
@Idempotent(keyExpression = "#paymentId + ':status_change:' + #request.status")
@RetryOnFailure(maxAttempts = 3, exponentialBackoff = true)
```

**금융 보안 매트릭스:**
- 🚨 **극도 제한**: 분당 5회 (슬라이딩 윈도우)
- 🔒 **완전 감사**: WARN 레벨로 모든 상태 변경 기록
- 🛡️ **중복 방지**: 동일 상태 변경 차단
- 🔐 **민감정보**: 자동 마스킹 처리

## 📈 보안 수준별 분류

### 🔥 Level 5 (최극도 보안)
- **토스 결제 승인**: 분당 3회, ERROR 감사
- **결제 상태 변경**: 분당 5회, WARN 감사

### 🚨 Level 4 (극도 보안)
- **주문 생성**: 분당 10회, 멱등성 보장
- **관리자 이벤트**: 시간당 5회

### 🔒 Level 3 (고도 보안)
- **결제 토큰 처리**: 분당 15회, 캐싱 적용
- **주문 상태 변경**: 분당 20회

### ⚡ Level 2 (성능 중심)
- **주문 조회**: 분당 30회, 캐싱 중심
- **결제 조회**: 분당 20-30회

### 📊 Level 1 (모니터링 중심)
- **통계 조회**: 분당 10회, 짧은 캐싱
